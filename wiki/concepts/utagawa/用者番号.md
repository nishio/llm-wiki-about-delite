# 用者番号

- **読み**: ようしゃばんごう
- **英語**: user number / user ID
- **種類**: [希哲館訳語](希哲館訳語.md)（一般用語「ユーザーID」の置き換え）

## 一言要約

デライトのユーザーアカウントを一意に区別する ID。`K#XXXX` のような 4桁16進の形式で表記される。

## 詳細

- 形式は `K#FD7E`、`K#804C`、`K#1` のような英数字（実体は知番系の番号）。
- 例:
  - `K#1` = [デライト公式](デライト公式.md) アカウント（KNo.1）
  - `K#FD7E` = zatsma 氏のアカウント
  - `K#804C` = 804C 氏のアカウント
- [輪符](輪符.md) `{知名 K#XXXX/XXXX}` の最初の `XXXX` 部分はこの用者番号、後半は輪郭の連番。つまり輪符は「**誰の・どの輪郭か**」を一意に指す形になっている。
- ユーザー側コミュニティでは「[デライト用語ではない](../デライト用語ではない.md)」（= 一般語の置き換えに過ぎず、覚えなくてもよい）と整理されている。
