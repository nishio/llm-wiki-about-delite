# 黄金

- **読み**: おうごん
- **種類**: 一般語の特殊用法（接頭辞として多数の派生語を生む）

## 一言要約

宇田川氏が「**宇田川の理想**」を意味する語として体系的に使う接頭辞・修飾語。「最も価値あるもの」の形容としての一般的な「黄金」から、希哲11年（[ジパング計画](ジパング計画.md) 開始）以後に「**知の黄金郷**」を連想させる意味で定着した。

## 本人による定義

宇田川氏自身の輪郭（[K#F85E/0758-450D](https://dlt.kitetu.com/KNo.F85E/0758-450D), 2025-02-13 描出）から:

> 最も価値あるものの形容として使われる「黄金」から、**概ね「宇田川の理想」という意味で定着した宇田川の用語**。
>
> [希哲館事業](希哲館事業.md) における [ジパング計画](ジパング計画.md)（希哲11年）以後、**無色透明な響きの「理想」よりも「知の黄金郷」を連想させる表現**として多用するようになった。

## 「黄金」を冠する用語の一覧

本人輪郭が列挙している派生語:

| 用語 | 大まかな意味 |
|---|---|
| 黄金人種 | 理想の人類像 |
| 黄金中立 | 政治的中立性のあり方の理想形 |
| 黄金状態 | 理想的な状態 |
| 黄金生活 | 理想の生活様式 |
| 黄金食（朝食 = 黄金朝食、本人輪郭 [K#F85E/0758-181A](https://dlt.kitetu.com/KNo.F85E/0758-181A)） | 理想の食事 |
| 黄金の日々 / 黄金日 / 黄金休日 / 黄金週 / 黄金月 / 黄金年 | 時間単位ごとの理想日 |
| 黄金循環 | 理想の生活サイクル |
| 黄金体 / 黄金顔面 / 黄金身長 | 理想の身体性 |
| [黄金整輪](大整輪.md#整輪との関係) | 大規模 [整輪](整輪.md) を理想的に進める段階 |

これ以外にも、本人輪郭で頻出する派生:

- **希哲黄金期**（暫定／本期）— 希哲館事業の歴史区分
- **希哲黄金体制** / **希哲黄金市場戦略**（第七次 [デライト市場戦略](デライト市場戦略.md)）
- **半希哲黄金月** — 一月の半分以上が黄金日になった状態

## 解釈上の注意

宇田川氏の輪郭を読み解くとき「黄金」が頭に付いた語が出てきたら、**「宇田川の現時点での理想形」** として捉えると意味が通る。日々の日記でも「希哲黄金日（黄金休日）」のように 1 日の評価語として頻繁に登場する。
