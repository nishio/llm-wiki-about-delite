## ソース概要

`/delite` プロジェクトは 2026 年 5 月に立ち上がった「[デライトユーザー向け井戸端](../concepts/Collabox.md)」。プロジェクト名は **「デライト Collabox（仮）」**。宇田川氏が井戸端で提案した造語 [Collabox](../concepts/Collabox.md)（= Cosense の改称案）をそのまま借りた愛称。

性格は **ユーザー言説の場** であり、宇田川氏本人の発言はほぼない。`hiro` ページは Cosense デフォルトの自己紹介テンプレートのみで、内容なし。主な書き手は `[zatsma.icon]`（K#FD7E、2025-12-25 から）と `[804C.icon]`。

そのため本ソースの主な価値は:

1. **デライトの記法・形式の実例**（`{知名 K#XXXX/XXXX}` の輪符書式、`K#1` 等の実際の用者番号）。
2. **未公開輪郭 vs プライベートプロジェクト** の運用比較（zatsma による分析表）。
3. **デコ二刀流の実例**（職業 = Cosense、それ以外 = デライト、というzatsmaの使い分け）。
4. **Collabox 構想の最初の実装** が存在するという事実そのもの。
5. メタ用語「[デライト用語ではない](../concepts/デライト用語ではない.md)」「[のような位置づけ](../concepts/のような位置づけ.md)」など、ユーザー側の自衛的修辞の登場。

宇田川氏の意図に直結する情報は薄いので、`villagepump-デライト.2hop` を主資料とした上での **補助資料** という位置づけ。

### 未公開輪郭 vs プライベートプロジェクト（zatsma の比較）

zatsma による 12 行表より特徴的なもの:

| 未公開輪郭 | プライベートプロジェクト |
| --- | --- |
| 運営者が常時閲覧可能である点が意識の片隅に残される | 心理的抵抗が小さい |
| 良くも悪くも俯瞰したくならなくなる | 良くも悪くも俯瞰したくなる |
| 縦方向の情報整理に長けてくるかも？ | 横方向の情報整理に長けてくるかも？ |
| 夢に宇田川さんが出てくる（実話） | 夢に shokai さんが出てくる（実話） |
| デラング記法の追求で時間を溶かす | UserScript, UserCSS の追求で時間を溶かす |
| 疑問を公開状態にすると開発者が拾ってくれることがある | 開発者に問い合わせする方法に迷いやすい |
| あたまのわるい時の私が使うようになる | あたまのいい時の私が使うようになる |

### 輪符の形式定義（zatsma による整理）

```
{あれ K#XXXX/XXXX}
```

- 知名の部分は好きに書き換えられる
- 引き入れや埋め込みに使う場合、知名部分は省略可（→ [無番輪符](../concepts/無番輪符.md)）
- 派生として「用者番号省略輪符」もある
