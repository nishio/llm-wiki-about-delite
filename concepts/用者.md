# 用者

- **読み**: ようしゃ
- **英語**: user
- **種類**: [希哲館訳語](希哲館訳語.md)（一般語「ユーザー」の言い換え）

## 一言要約

「ユーザー」の希哲館訳語。デライトでは公式の用語として用いられている。ただし [zatsma.icon] の整理では「デライト用語ではない」とされ、覚える必要のあるデライト固有語ではなく、希哲館全体で使う一般語の置き換え、という位置づけ。

## 詳細

- デライト UI 上では「用者ページ」「用者番号」のように現れる。
- カタカナ語を漢字に置き換える希哲館訳語の方針に沿った造語。
- ユーザー側コミュニティでは「**[デライト用語ではない](デライト用語ではない.md)**」として、初学者が無理に覚えなくてよい用語に分類されている。
