# 複合的階層構造SNSとしてのデライトの紹介

- **種類**: 久住哲による紹介ページ

## 一言要約

「[デライト](デライト.md) は投稿を **複合的な階層構造** にできる SNS」という、一般 SNS との対比を軸にしたデライト紹介。

## 詳細

一般 SNS との対比:

- 一般 SNS でも、投稿にレスをすることでスレッドを作れる。レスにレスを付けることもできる。
- だが、それは「自分のレスが特定の親レスにぶら下がる」という **一本のツリー** に限られる。

デライトの違い:

- デライトの輪郭は、**複数の別な輪郭のレスに位置づけられる**。
- これにより階層的関係づけが自由自在になる。
- 結果として **複合的な階層構造** ができる。

[輪郭構造](輪郭構造.md) の SNS 観点からの言い直し、とも言える。
