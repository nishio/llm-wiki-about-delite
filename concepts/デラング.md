# デラング

- **英語**: Delang
- **種類**: 造語（マークアップ言語名）

## 一言要約

宇田川氏が開発しているデライト向けの簡易マークアップ言語。Markdown や Scrapbox 記法と同類のもの。

## 詳細

- 「デ（ライト）＋ラング（lang）」。
- [パンくず記法](パンくず記法.md) など独自記法を含む。
- 強調記法と併用しないリンクは目立たない装飾でレンダリングされ、閲覧専用モードでは非リンク化されて普通の文書のように見える（[意味符号化](意味符号化.md) の運用）。

## 主な記法

久住哲氏が整理したもの:

- **輪符（タグっぽいやつ）**: `{}` で囲む。
- **見出し**: `* `, `# `, `= `
- **コメント**: `!-`, `!!-`, `!!!-`, `!?-`, `!??-`
- **キー記法**: `[_あああ_]`
- **箇条書き**: `・`, `-`
- **コード**: インライン `` `...` ``、ブロック ` ``c ... `` `
- **矢印（前次記法）**: `<-`, `->`
- **キラキラ星**: `★★`
- **引用**: `>`
- **水平線**: `---`
- **ルビ**: `(^ )`
- **顔アイコン**: `{:`
- **[パンくず記法](パンくず記法.md)**: `A > B > C >`（見た目だけ変わる）
- **色見本**: `%%(red)`
- **ダッシュ記法**: `>>` 〜 `<<` でくくる引用＋出典フォーマット
- **主述記法**: `hogehoge::` の形

久住氏が「よく使う」のは パンくず記法 と 主述記法。
